## What this means {#what-this-means}

This browser lets only one tab send changes at a time.

You can keep using every tab — they all share the same local data. One tab quietly handles the syncing for all of them.

## What to do {#what-to-do}

You can keep working — WCPOS handles this automatically. Do not retry — the result will not change.

## Your data {#your-data}

No order or product data is affected.

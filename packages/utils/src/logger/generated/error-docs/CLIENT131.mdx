## What this means {#what-this-means}

WCPOS queued too many requests at once and dropped some.

This is usually an app defect rather than a store problem. Restart WCPOS; if the code returns, export diagnostics and contact support.

## What to do {#what-to-do}

Export diagnostics and contact support. WCPOS does not retry this by itself — retry when you are ready.

## Your data {#your-data}

No order or product data is affected. If this persists, export diagnostics and contact WCPOS support.

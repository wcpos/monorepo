## What this means {#what-this-means}

Your store is limiting requests temporarily, so this action will retry later.

Wait before retrying. If rate limits continue, ask the site administrator or host to review the store's request limits.

## What to do {#what-to-do}

Try the action again. WCPOS retries this automatically.

## Your data {#your-data}

The change is saved on this device but has not reached your store. If this persists, ask the person who manages your WordPress site.

## Details {#details}

- **Code:** `SYNC141` (`STORE_RATE_LIMITED`)
- **Severity:** warn
- **Introduced in:** WCPOS 1.10.0

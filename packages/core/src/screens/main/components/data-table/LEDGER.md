Sorting goes directly through query actions and persisted UI settings, not TanStack’s sorting state; column IDs are normalized to query fields — avoids the custom sorting-state mismatch that broke header sorting — evidence: `685d04404f 2026-03-10 fix: remove TanStack from sorting loop — use UI settings directly`; `header.test.tsx`: “maps price column to sortable_price”, “keeps the semantic order total field for the translator” — platform: all.
2. 3. Sortable headers stretch across the whole cell while retaining column alignment — clicks in otherwise empty header space must still sort — evidence: `f2666fb5a4 2026-04-08 fix: make column header Pressable fill entire cell for reliable click targeting` — platform: all, reported on web.
4. Applied sorting exposes a field-and-direction testID — local sorting cannot reliably be verified through network requests — evidence: “specs steering the sort need a DOM signal, not a network one.” (`components/data-table/header.tsx:70`) — platform: web/Electron.
5. Virtualized rows use record identity rather than position — expanded state and cell Suspense must follow records across sorting — evidence: `e6a965a647 2026-08-04 fix(components): give data-table rows record identity, not position` — platform: all.

7. Column visibility and caller state are passed as list `extraData` — native list cells otherwise miss relevant state changes — evidence: `4460112ded 2025-07-09 Add extraData prop for FlashList to force re-renders` — platform: iOS/Android.
8. 9. Cell selection supports flat and row-dependent maps with a central text fallback — prevents screens from drifting into inconsistent rendering of the same fields — evidence: `f3ec0f150c 2026-08-22 refactor(data-table): take a cells map instead of a render function` (issue #1480) — platform: all.
10. Each default cell has its own Suspense inside an error boundary — an image attachment loading must not suspend the entire table — evidence: `4f2d370975 2026-06-11 refactor(core): load image attachments via suspense resources, not effects` — platform: all, originating in web image loading.
11.

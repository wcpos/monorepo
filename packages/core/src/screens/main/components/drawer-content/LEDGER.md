The rules for preserving or striking a line are in the [library strategy](https://github.com/wcpos/roadmap/blob/worktree-docs%2Bdesign-program-2026-09-12/docs/design/2026-09-18-library-strategy.md), section 3. **Job:** Render responsive drawer navigation, notification/version access, visibility reporting, and unread-log badges.

**Composes:** `@wcpos/components/{badge,button,dialog,hstack,icon,lib/utils,text,tooltip,vstack}`.

## Lines

1. Permanent items are icon-only, with tooltip wrapping only on web; ordinary drawers retain labels — native navigation buttons must remain directly operable — evidence: `eee1eef4dd 2025-09-30 fix drawer buttons on native`; “Only wrap with tooltip on web” (`components/drawer-content/drawer-item.tsx:100`) — platform: all.
2. Drawer-owned context hooks must live in rendered children, not the `DrawerContent` function body — the library invokes that function above its own providers, previously crashing both native and web — evidence: `42db0baa18 2026-08-30 fix(drawer): move the progress watcher out of DrawerContent's body`; explanation at `components/drawer-content/index.tsx:20–27` — platform: all.
3. Start hidden, unhide on opening, and hide only after a one-second close-settle window; reopening cancels the pending hide — prevents stale animated values from resurrecting a closed drawer without clipping its close animation — evidence: `ca7c4da9e9 2026-08-30 fix(drawer): hide the closed drawer panel instead of only translating it` (issue #1691); settle/reopen tests in `panel-visibility.test.tsx` — platform: iOS/Android, particularly Fabric.
4. Never briefly drop and reapply the settled-closed hide; coordinate panel/overlay hiding with the library patch — delayed reassertion previously redrew the drawer, while a stale overlay intercepted touches — evidence: `d614610f2b 2026-09-03 fix(drawer): hide a settled-closed panel in the library's own worklet; drop the re-assert path`; `drawer-layout-overlay-patch.test.ts`: “hides the overlay together with the panel” — platform: iOS/Android.
5. Explicitly hide closed-panel descendants from assistive technology — Android retained stale accessible bounds even when nothing was drawn — evidence: `4c01b3755e 2026-09-03 fix(drawer): hide a hidden panel's items from assistive tech` — platform: Android; accessibility props also cover iOS.
6. Exempt permanent drawers from accessibility hiding — their navigator state says “closed” despite the visible rail — evidence: `a26e5e1094 2026-09-03 fix(drawer): never hide a permanent drawer from assistive tech`; matching permanent-drawer test in `drawer-content-render.test.tsx` — platform: all.
7. Permanent and dismissible panels expose different testIDs — tablet automation must not wait for an always-visible rail to close — evidence: `30bd2e1f8b 2026-09-03 fix(e2e-native): tablets keep their rail, phones reach the + tab` — platform: all; demonstrated on Android tablets.
8. Drawer scroll content uses `flexGrow: 1`, not fixed full height — lower navigation items must remain reachable on short viewports — evidence: `e9b4a62223 2026-08-21 fix(drawer): make nav item column scrollable on short viewports` (issue #1425) — platform: all.
9. Unread-error state persists a last-viewed timestamp across restarts — reopening the app must not mark every retained error unread — evidence: `800028aa6c 2026-07-31 feat(health): shared component vocabulary + Logs flat ledger (#843)` — platform: all.
10. Initialize a missing watermark to now before counting; if persistence fails, keep the badge at zero — upgrades must not flood the badge with retained history — evidence: `760f328a80 2026-07-31 fix(logs): pin diagnostic expiry and unread migration`; both migration-ordering tests in `logs-badge.test.tsx` — platform: all.
11. Follow replacement log collections after recovery and absorb badge-storage errors — the badge must neither freeze on the removed collection nor crash navigation — evidence: `18397b6774 2026-08-25 fix(query): one collection-following hook, and it checks the owner`; “The badge is decoration — storage trouble must not crash the drawer.” (`components/drawer-content/logs-badge.tsx:101`) — platform: all.
12. About information suppresses duplicate app/platform versions and prefers the Pro plugin version when present — keeps diagnostic version information distinguishable rather than duplicating equivalent rows — evidence: `5d587781d6 2026-01-22 Add version info & uniwind Pro`; “Show Pro version if present, otherwise show free version” (`components/drawer-content/version.tsx:77`) — platform: all.

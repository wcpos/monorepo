## Lines

1. Permanent items are icon-only, with tooltip wrapping only on web; ordinary drawers retain labels — native navigation buttons must remain directly operable — evidence: `eee1eef4dd 2025-09-30 fix drawer buttons on native`; the rail presentation's web-only `Tooltip` around its `NavItem` (`components/drawer-content/index.tsx`, since card 11, 2026-10-28) — platform: all.
2. Drawer-owned context hooks must live in rendered children, not the `DrawerContent` function body — the library invokes that function above its own providers, previously crashing both native and web — evidence: `42db0baa18 2026-08-30 fix(drawer): move the progress watcher out of DrawerContent's body`; explanation in the NOTE ON HOOKS on `DrawerContent` (`components/drawer-content/index.tsx`) — platform: all.
3. Start hidden, unhide on opening, and hide only after a one-second close-settle window; reopening cancels the pending hide — prevents stale animated values from resurrecting a closed drawer without clipping its close animation — evidence: `ca7c4da9e9 2026-08-30 fix(drawer): hide the closed drawer panel instead of only translating it` (issue #1691); settle/reopen tests in `panel-visibility.test.tsx` — platform: iOS/Android, particularly Fabric.
4. Never briefly drop and reapply the settled-closed hide; coordinate panel/overlay hiding with the library patch — delayed reassertion previously redrew the drawer, while a stale overlay intercepted touches — evidence: `d614610f2b 2026-09-03 fix(drawer): hide a settled-closed panel in the library's own worklet; drop the re-assert path`; `drawer-layout-overlay-patch.test.ts`: “hides the overlay together with the panel” — platform: iOS/Android.
5. Explicitly hide closed-panel descendants from assistive technology — Android retained stale accessible bounds even when nothing was drawn — evidence: `4c01b3755e 2026-09-03 fix(drawer): hide a hidden panel's items from assistive tech` — platform: Android; accessibility props also cover iOS.
6. Exempt permanent drawers from accessibility hiding — their navigator state says “closed” despite the visible rail — evidence: `a26e5e1094 2026-09-03 fix(drawer): never hide a permanent drawer from assistive tech`; the rail is the `rail` presentation since card 11 (2026-10-28), pinned in `index.test.tsx` — platform: all.
7. Permanent and dismissible panels expose different testIDs — tablet automation must not wait for an always-visible rail to close — evidence: `30bd2e1f8b 2026-09-03 fix(e2e-native): tablets keep their rail, phones reach the + tab` — platform: all; demonstrated on Android tablets.
8. Drawer scroll content uses `flexGrow: 1`, not fixed full height — lower navigation items must remain reachable on short viewports — evidence: `e9b4a62223 2026-08-21 fix(drawer): make nav item column scrollable on short viewports` (issue #1425) — platform: all.
9. Unread-error state persists a last-viewed timestamp across restarts — reopening the app must not mark every retained error unread — evidence: `800028aa6c 2026-07-31 feat(health): shared component vocabulary + Logs flat ledger (#843)` — platform: all.
10.

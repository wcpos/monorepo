# Behaviour ledger: `pos/cart`

`v2/` folded into this directory on 2026-10-15; read `v2/x` as `x`; `v2/LEDGER.md` is now `cart.LEDGER.md`

Seeded 2026-09-18 from `.claude/research/2026-09-18-composed-behaviour-ledger.md` on `research/composed-ledger` (wcpos/roadmap#341) by wcpos/roadmap#345. Numbers are assigned once and never reused: a struck line leaves a gap, a new line takes the next number. Every line keeps its evidence. The rules for preserving or striking a line are in the [library strategy](https://github.com/wcpos/roadmap/blob/worktree-docs%2Bdesign-program-2026-09-12/docs/design/2026-09-18-library-strategy.md), section 3. Not reworded from the source.

**Job:** Compose cart editing, totals, open-order navigation, checkout summaries and register-session workflows.

**Composes:** `@wcpos/components/{button,card,collapsible,combobox,dialog,docs-link,dropdown-menu,error-boundary,form,hstack,icon,icon-button,input,status-badge,suspense,table,tabs,text,toast,tooltip,vstack}`; helpers/types from `combobox/types`, `tree-combobox`, `lib/utils`.

2026-10-14: the v1 `table.tsx`, `tabs.tsx`, `tab-chip.tsx` and `cart-header.tsx` files cited as evidence in lines 4–7, 11, 13, 15, 17 and 79 were deleted; those behaviours are carried by the `v2/` owners named for the same line numbers in `v2/LEDGER.md`, except line 79, which names `v2/tab-chip.tsx` here.

2026-10-21: line 7's "authorized legs count as paid" is superseded by ADR 0040 D6: only captured money counts toward paid, and an authorization is a hold, as the store counts it (`Ledger::COUNTING_STATUSES`). `tab-chip.tsx` reads Partly paid from captured rows only, the same set `derive()` counts.

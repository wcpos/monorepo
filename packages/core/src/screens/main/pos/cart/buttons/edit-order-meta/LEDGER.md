The hand-over is one box (2026-10-30, design v2 approved by Paul): a `Notice` (`live={false}`: it holds pickers) holding the four conditions of the cart's open-orders scope (`openOrdersSelector`) — Status, Cashier, Store (only when the credential holds more than one store) and Register (only when the chosen store's directory has registers) — then a footer with one before → after per changed field beside the Send. Two amber recipes: the band (`tone="warning"`) once anything is staged, and `tone="attention"` on each changed picker. Whether the order leaves this cart is computed once from the four conditions (pos-open → pending stays): the footer reads “Leaves this cart” or “Stays in this cart”, the confirm says “It stays in this cart.” when it stays, and only a leaving order is dropped from the cart. Changing Store resets Register (the order's own on the way back; the only one, written once the target store's directory answers); Send waits for that directory, then for a register when it has some; a store with none clears the order's register (`stampIdentity` `registerId: null`, an empty value, since protected meta cannot be dropped). Send also waits for a newly picked cashier's name. The confirm names the target: the cashier, else Store · Register, else the store — evidence: test `form.test.tsx`, describe “the hand-over box”; `carrier.test.ts` “a null register clears the row…” — platform: all.
